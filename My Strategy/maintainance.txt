# Complete Setup Guide for SENSEX Trading Bot

## 1. Prerequisites & Account Setup

### A. Trading Account Requirements
- **Dhan Trading Account**: Open a trading account with Dhan Securities
- **API Access**: Enable API trading in your Dhan account
- **Sufficient Balance**: Ensure adequate funds for option trading (minimum ₹50,000-1,00,000 recommended)

### B. Python Environment
```bash
# Install required Python packages
pip install pandas dhanhq requests
```

## 2. API Credentials Setup

### A. Dhan API Credentials
1. **Login to Dhan**: Go to Dhan web/app
2. **API Section**: Navigate to Settings → API
3. **Generate Credentials**:
   - Client ID (your unique identifier)
   - Access Token (for API authentication)
4. **Replace in code**:
   ```python
   CLIENT_ID = "your_actual_client_id"
   ACCESS_TOKEN = "your_actual_access_token"
   ```

### B. Telegram Bot Setup (Optional but Recommended)
1. **Create Bot**:
   - Open Telegram, search for @BotFather
   - Send `/newbot` command
   - Follow instructions to create bot
   - Get Bot Token (looks like: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

2. **Get Chat ID**:
   - Start chat with your bot
   - Send any message
   - Visit: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Find your chat ID in the response

3. **Update code**:
   ```python
   TELEGRAM_BOT_TOKEN = "your_bot_token_here"
   TELEGRAM_CHAT_ID = "your_chat_id_here"
   ```

## 3. Required Files

### A. API Script Master CSV File
**File Name**: `api-scrip-master.csv`
**Location**: Same folder as your Python script

**How to get this file**:
1. **From Dhan**: Download from Dhan API documentation/resources
2. **Typical URL**: Check Dhan's developer portal for master file
3. **Manual Creation**: Create CSV with these columns:
   ```csv
   token,symbol,name,expiry,strike,lotsize,instrumenttype,exch_seg,tick_size
   ```

**Sample entries for SENSEX options**:
```csv
token,symbol,name,expiry,strike,lotsize,instrumenttype,exch_seg,tick_size
12345,SENSEX09JUL2582000PE,SENSEX 09JUL25 82000 PE,2025-07-09,82000,20,OPTIDX,BSE_EQ,0.05
12346,SENSEX09JUL2582100PE,SENSEX 09JUL25 82100 PE,2025-07-09,82100,20,OPTIDX,BSE_EQ,0.05
```

### B. Day-wise Trading Parameters
The code has different parameters for each day:
- **Monday**: 4 lots, Target1: 30, Target2: 45, SL: 25

- **Wednesday**: 2 lots, Target1: 35, Target2: 45, SL: 25
- **Thursday**: 3 lots, Target1: 35, Target2: 45, SL: 25
- **Friday**: 4 lots, Target1: 30, Target2: 40, SL: 25

## 9. Common Issues & Solutions

### A. CSV File Issues
- **Problem**: Token not found
- **Solution**: Update CSV with current week's option symbols

### B. API Connection Issues

- **Solution**: Check credentials, ensure API is enabled

### C. Order Failures

- **Solution**: Check balance, trading permissions, market hours
